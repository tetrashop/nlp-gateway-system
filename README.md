# 🚀 NLP Gateway System

سیستم پردازش زبان طبیعی با ۱۶۸ پست تخصصی

## 📋 ویژگی‌ها

- پردازش ۱۶۸ پست تخصصی NLP
- API کامل RESTful
- جستجوی پیشرفته فارسی
- تحلیل احساسات متن
- مدیریت خودکار Git

## 🏃 شروع سریع

```bash
# کلون پروژه
git clone https://github.com/tetrashop/nlp-gateway-system.git
cd nlp-gateway-system

# نصب وابستگی‌ها
npm install

# اجرای سرور
npm start

# یا با اسکریپت مدیریت
./manage.sh start
