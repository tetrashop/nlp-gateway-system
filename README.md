# 🚀 NLP Gateway – درگاه پردازش زبان طبیعی روی Termux بدون اینترنت

**نسخه ۸.۰ | پایدار و کامل**  
یک سرویس RESTful قدرتمند برای تحلیل احساسات، ترجمه، خلاصه‌سازی، تشخیص موجودیت، جستجو، تبدیل صدا به متن و مدیریت API – کاملاً آفلاین و سبک.

---

## 📖 درباره پروژه

پروژه `nlp-gateway` حاصل تلاش برای ساخت یک **درگاه پردازش زبان طبیعی** کاملاً مستقل از اینترنت است که روی **Termux** (اندروید) اجرا می‌شود. در این مسیر با چالش‌های متعددی روبرو شدیم: خطاهای `Address already in use`، مشکل در سرویس فایل‌های استاتیک، ناهماهنگی مسیرهای API، تنظیم `nohup` برای اجرای دائم، و اتصال به مخزن گیت‌هاب. تمام این مشکلات با توسعه تدریجی و اضافه شدن ۸ قابلیت اصلی رفع گردید.

اکنون این پروژه یک **سرور HTTP کامل** با پشتیبانی از:
- تحلیل احساسات (فارسی/انگلیسی)
- ترجمه ساده (با دیکشنری داخلی)
- خلاصه‌سازی متن
- تشخیص موجودیت‌ها (تاریخ، شماره موبایل، ایمیل)
- فیلتر کلمات نامناسب
- تبدیل اعداد فارسی به انگلیسی
- شمارش کلمات و جملات
- پاکسازی متن
- **موتور جستجو** روی پست‌های ذخیره‌شده
- **داشبورد مدیریت تحت وب**
- **تبدیل صدا به متن** (با pocketsphinx)
- **ذخیره‌سازی در SQLite** و کش نتایج
- **خروجی XML و YAML**
- **مدیریت API Key** (چند کاربره)
- **WebSocket ساده** (روی پورت 8081)
- **بکاپ‌گیری خودکار به ابر** (با rclone)
- **پشتیبانی از Docker و docker-compose**
- **اتصال به ربات بله (Bale)** برای پاسخ‌گویی هوشمند

است.

## 🏗 معماری و فناوری‌ها

- **زبان:** Python 3.12 (استاندارد، بدون نیاز به کتابخانه‌های سنگین)
- **سرور:** `http.server` از کتابخانه استاندارد (بدون FastAPI/Flask)
- **دیتابیس:** SQLite (محلی، بدون نیاز به تنظیم)
- **پردازش متن:** Regex و دیکشنری‌های داخلی
- **تشخیص صدا:** pocketsphinx (آفلاین)
- **وب‌سوکت:** پیاده‌سازی ساده با سوکت‌های TCP
- **مستندات:** HTML/CSS/JS خالص (داشبورد مدیریت)

> **نکته:** تمام مدل‌های پردازش متن بر اساس قواعد و لغت‌نامه‌های دستی ساخته شده‌اند؛ بنابراین **هیچ وابستگی به اینترنت** ندارند.

## ✨ قابلیت‌های کامل (۸ ویژگی اصلی + افزونه‌ها)

| ردیف | قابلیت | توضیح |
|------|--------|-------|
| ۱ | **داشبورد مدیریت وب** | صفحه HTML با جاوااسکریپت که وضعیت سرور، تعداد پست‌ها و آپ‌تایم را نمایش می‌دهد. |
| ۲ | **ربات بله (Bale)** | اسکریپت `bale_bot.py` که پیام‌های دریافتی را تحلیل احساسات و خلاصه‌سازی می‌کند. |
| ۳ | **موتور جستجو** | جستجوی متن در تمام فایل‌های `.txt` و `.md` پوشه `posts` با نمایش عنوان و بخشی از محتوا. |
| ۴ | **تبدیل صدا به متن** | با `pocketsphinx`، فایل WAV را به رشته متنی تبدیل می‌کند (الگوی `speech2text.py`). |
| ۵ | **پشتیبانی از PostgreSQL** | فایل `db_pg.py` برای اتصال به دیتابیس سنگین‌تر (اختیاری). |
| ۶ | **بکاپ خودکار به ابر** | اسکریپت `backup_cloud.sh` که از پوشه پروژه بکاپ گرفته و با `rclone` به فضای ابری می‌فرستد. |
| ۷ | **کانتینر داکر** | `Dockerfile` و `docker-compose.yml` برای اجرای آسان در هر سرور لینوکسی. |
| ۸ | **API‌های پیشرفته** | شامل مسیرهای `/health`, `/v1/sentiment`, `/v1/translate`, `/api/search`, `/v1/summarize`, `/v1/filter`, `/v1/entities` و غیره. |

## 🛠 نصب و راه‌اندازی (روی Termux)

### ۱. بازیابی پروژه از بکاپ (در صورت نیاز)
```bash
cd ~
tar -xzvf /sdcard/Download/nlp-gateway-backup.tar.gz
cd nlp-gateway
```

۲. پیش‌نیازها

· Termux با دسترسی به حافظه (اجرای termux-setup-storage)
· Python 3.12 (در Termux به‌طور پیش‌فرض نصب است)

۳. اجرای سرور (روش ساده)

```bash
cd ~/nlp-gateway
python server.py
```

سپس سرور روی پورت ۱۶۸۱ (یا پورت آزاد بعدی) شروع به کار می‌کند.

۴. اجرای دائم (در پس‌زمینه)

```bash
nohup python server.py > server.log 2>&1 &
echo $! > server.pid
```

۵. بررسی سلامت سرور

```bash
curl http://localhost:1681/health
# پاسخ: {"status": "ok", "version": "8.0"}
```

۶. تست داشبورد مدیریت

در مرورگر گوشی آدرس زیر را باز کنید:

```
http://localhost:1681/dashboard.html
```

۷. نمونه درخواست‌ها

تحلیل احساسات

```bash
curl -X POST http://localhost:1681/v1/sentiment \
  -H "Content-Type: application/json" \
  -H "X-API-Key: test-key-123" \
  -d '{"text": "این پروژه فوق‌العاده است"}'
```

ترجمه (فارسی به انگلیسی)

```bash
curl -X POST http://localhost:1681/v1/translate \
  -H "Content-Type: application/json" \
  -H "X-API-Key: test-key-123" \
  -d '{"text": "سلام دوست", "source": "fa", "target": "en"}'
```

جستجو در پست‌ها

```bash
curl "http://localhost:1681/api/search?q=NLP"
```

مشکل علت راه‌حل
OSError: [Errno 98] Address already in use پورت ۱۶۸۰ یا ۱۶۸۱ توسط فرآیند دیگر اشغال شده است. با pkill -f "python server.py" سرور را متوقف کنید یا پورت را تغییر دهید.
Cannot GET /dashboard.html سرور فایل‌های استاتیک را سرویس نمی‌داد. متد do_GET اصلاح شد تا فایل dashboard.html را مستقیماً برگرداند.
خطا در ارتباط با سرور در داشبورد داشبورد از /api/health استفاده می‌کرد در حالی که سرور فقط /health را داشت. با sed مسیر داخل dashboard.html اصلاح گردید.
fatal: 'origin' does not appear to be a git repository مخزن راه دور تعریف نشده بود. با git remote add origin <url> اضافه شد.
src refspec master does not match any شاخه محلی master وجود نداشت. با git branch -M master نام شاخه را اصلاح کردیم.
nohup: ignoring input و خروج زودهنگام سرور بدون توانایی بایند پورت اجرا می‌شد. ابتدا پورت را آزاد کرده، سپس nohup اجرا شد.

📦 مدیریت پروژه

توقف سرور

```bash
pkill -f "python server.py"
```

تغییر پورت دلخواه

فایل server.py را ویرایش کرده و خط host, port = '0.0.0.0', 1681 را تغییر دهید.

```bash
./backup_cloud.sh
```
